    Connect your channel

    Part A gives you public stats. Part B adds private Analytics (watch time, retention, traffic, real subscriber growth). Part C turns your values into a prompt you can send back to me.

    Part A: YouTube Data API (public stats)

    1. Create a Google Cloud project: New project.
    2. Enable the API: YouTube Data API v3 → Enable.
    3. Create an API key: Credentials → Create credentials → API key. Restrict it to YouTube Data API v3 and to your site as an HTTP referrer. Docs.
    4. Find your channel ID: advanced settings. It starts with UC. Your @handle also works.

    Part B: YouTube Analytics API (private stats)

    1. Enable it: YouTube Analytics API → Enable (same project).
    2. Set up the consent screen: OAuth consent screen. Choose External, fill the app name and your email, then add your own Google account under Test users. Keep the app in Testing mode.
    3. Create an OAuth client ID: Create OAuth client → Web application. Under Authorized JavaScript origins add the exact address you open the dashboard from, such as http://localhost:8000 or https://yoursite.com. Copy the client ID, which ends in .apps.googleusercontent.com. How this sign-in works.
    4. Open the dashboard from a web server (python3 -m http.server 8000 in the folder) and press Connect Analytics. Google shows an “unverified app” notice because it is your own test app. Click Advanced, then continue.

    Opening the file straight from your computer? Sign-in can't redirect back, so skip steps 6 to 8: open Google OAuth Playground, paste into the scope box at the bottom of Step 1, press Authorize APIs, then in Step 2 press Exchange authorization code for tokens and copy the Access token (starts with ya29.). Paste it into the Access token field in Part C. It lasts about an hour.

    Reference: channel reports, metrics list, YouTube Studio for impressions and CTR. Data API quota is 10,000 units a day (costs).

    Part C: Fill in, then copy the prompt

    Leave anything blank that you don't have yet. Nothing here is sent anywhere until you paste the prompt into the chat.

    The prompt contains your API key. Only paste it into this chat, and keep the key restricted to your site so it is useless elsewhere.

    Add a channel

    Public stats (videos, views, SEO, forecast) work for any channel with just its ID or @handle. Private Analytics needs a token from a Google account that owns or manages that channel, so each channel gets its own token. In the OAuth Playground, pick that channel when Google asks which one to use.

    Channels you add here are remembered in this browser (names and IDs only, never tokens). To make them permanent, send me the IDs and I'll hard-code them into EXTRA_CHANNELS.
